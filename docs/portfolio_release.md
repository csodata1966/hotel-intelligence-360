# Checklist de publicação v1.0.0

1. Não instalar o adaptador R2/S3 do MVP 0.7; ele não é necessário na Portfolio Edition.
2. Fazer backup do repositório e dos dados locais. Aplicar somente os arquivos do pacote incremental.
3. Validar a suite de testes e executar as cinco abas localmente.
4. Conferir a Visão Executiva quando o Gold local não existir: população e PIB devem surgir do snapshot, com ano e data.
5. Conferir feriados, clima e simulação e a correta distinção entre dados reais e simulados.
6. Registrar commit e tag v1.0.0 somente após validação; enviar ambos ao GitHub.
7. Conferir GitHub Actions e depois o Streamlit Community Cloud.
8. Adicionar ao Universo Dados: captura de tela, link para aplicação, link para repositório, problema de negócio, arquitetura e limitações.
